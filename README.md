### Project 3: Poseidon2哈希电路的Circom实现

1. **参数设置**:
   - 采用(n,t,d) = (256,3,5)或(256,2,5)
   - 参考[Poseidon2论文](https://eprint.iacr.org/2023/323.pdf) Table 1

2. **电路设计**:
   - 公共输入：Poseidon2哈希值
   - 隐私输入：哈希原像（单块输入）

3. **证明系统**:
   - 使用Groth16算法生成证明
   - 参考资源：
     - [Circom文档](https://docs.circom.io/)
     - [Circomlib示例](https://github.com/iden3/circomlib)

4. 目标：完整的ZK-SNARK可验证哈希电路
